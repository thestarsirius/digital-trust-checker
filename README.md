# فاحص الاحتيال الرقمي | Digital Trust Scam Checker

أداة مجانية بالعربي تساعدك تعرف إذا كان رابط أو رسالة وصلتك مشبوهة، مع اختبار تفاعلي من 8 رسائل بأسلوب الاحتيال المنتشر محلياً.

A free Arabic-first tool that flags suspicious links and messages, plus an 8-question phishing quiz. Everything runs client-side: **no data leaves your browser**.

**Live demo:** [ضع رابط GitHub Pages هنا]

## المميزات / Features

- **فاحص الروابط والرسائل:** يعطي تقييماً من 100 مع شرح كل علامة خطر.
- **اختبار الاحتيال:** 8 رسائل (احتيال وسليمة) مع شرح بعد كل إجابة.
- **خصوصية كاملة:** صفحة HTML واحدة، بدون خادم، بدون تخزين، بدون تتبع.
- **فحص إضافي:** زر يفتح الرابط في VirusTotal (بطلب منك فقط).

## كيف يفحص؟ / How it works

الفحص قائم على قواعد (heuristics) مبنية على علامات معروفة في هجمات التصيّد:

| الفئة | أمثلة |
|---|---|
| شكل الرابط | عنوان IP بدل اسم موقع، Punycode، علامة `@`، منفذ غير معتاد، رابط مختصر |
| النطاق | نهايات شائعة في الاحتيال (`.top`, `.icu`, `.cfd`...)، نطاقات فرعية كثيرة |
| انتحال العلامات | نطاق يحتوي اسم جهة معروفة (أبشر، نفاذ، بنوك، شحن...) وهو ليس نطاقها الرسمي |
| نص الرسالة | استعجال وتهديد، جوائز، دفع رسوم، طلب رمز التحقق أو بيانات حساسة |

## حدود الأداة / Limitations

- الفحص قائم على علامات، وليس على قاعدة بيانات تهديدات حية. النتيجة المنخفضة **لا تعني أن الرابط آمن**.
- قد تظهر نتائج خاطئة (إيجابية أو سلبية). استخدم الأداة للتوعية وليس كبديل عن الحذر.
- النسخة القادمة: ربط اختياري بـ Google Safe Browsing وVirusTotal عبر خادم وسيط يحمي مفاتيح الـ API.

## التشغيل محلياً / Run locally

افتح `index.html` في المتصفح. لا يحتاج تثبيتاً.

## النشر على GitHub Pages

1. ارفع `index.html` و`README.md` إلى مستودع جديد.
2. من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. بعد دقائق يظهر رابط الموقع.

## الأمان / Responsible use

الأداة دفاعية وتوعوية فقط. الرسائل في الاختبار مكتوبة لأغراض التعليم وتستخدم نطاقات وهمية. لا تستخدم الأداة أو محتواها لأي نشاط ضار.
